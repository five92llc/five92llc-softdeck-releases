# SoftDeck releases

Installers and auto-update files for **SoftDeck**, a software HyperDeck-compatible clip player for
ATEM switchers and Bitfocus Companion.

Download the latest version from the [Releases](../../releases) page:

- **Windows:** `SoftDeck-Setup-x.y.z.exe`
- **macOS:** `SoftDeck-x.y.z.dmg` (Apple Silicon: `-arm64`)

Installed copies of SoftDeck check this repository for updates. The source code lives in a separate private repository.
